# Telegram-бот IMER

Бот-консультант студии: отвечает клиенту сразу, в любое время, и передаёт вам готовую заявку.

## Что умеет

| Кнопка | Что делает |
|---|---|
| 🧭 Подобрать услугу | 3 вопроса → пакет, цена «от» и почему он подходит |
| 💰 Цены | Цены по направлениям + КП в PDF одним файлом |
| 🖼 Кейсы | 5 проектов с картинками и цифрами |
| 🤔 Есть сомнения | 12 частых возражений: «дорого», «сделаю сам», «есть фрилансер», «боюсь, что не то», «нет времени», «надо подумать», «долго», «зачем предоплата», «окупится ли», «обжигался», «агентство надёжнее», «нестандартная задача» |
| 📝 Оставить заявку | 4 шага за 2 минуты, задачу можно наговорить голосовым |
| 🎓 Обучение | Тест на 3 вопроса + квест для дизайнеров с гайдом в подарок |
| 🎁 Полезное | Советы для дизайнеров и селлеров |
| 💬 Задать вопрос человеку | Вопрос приходит вам, вы отвечаете — ответ уходит клиенту |

Если клиент просто пишет текст, бот ищет в нём сомнение («а не дорого?», «я лучше сам в тильде») и отвечает. Если не понял — пересылает сообщение вам.

**Как отвечать клиенту:** в чате с ботом нажмите «Ответить» (reply) на карточку заявки или вопроса и напишите ответ. Бот отправит его клиенту от имени IMER.

Заявки приходят вам в Telegram. Если указать `LEADS_URL`, они попадут ещё и в ту же Google-таблицу, что заявки с сайта.

## Запуск за 10 минут

### 1. Закройте старый токен — обязательно
Старый токен был вписан прямо в код и попал в архив, значит его могут использовать посторонние.
В Telegram откройте **@BotFather** → `/mybots` → старый бот → **API Token** → **Revoke current token**.

### 2. Создайте бота
В **@BotFather**: `/newbot` → имя `IMER` → адрес, оканчивающийся на `bot`, например `imer_studio_bot`.
Адрес студии: `@imerbot_bot`, он уже стоит на сайте, в КП и в гайде.
BotFather пришлёт токен вида `1234567890:AAE...`.

Можно и обновить старого бота: `/mybots` → бот → **Edit Bot** → имя и фото. Тогда адрес останется прежним.

### 3. Запустите
1. Установите Python 3.11 или новее, если его нет (при установке отметьте **Add Python to PATH**).
2. Дважды щёлкните `zapusk.bat`. Откроется файл `.env` — впишите `BOT_TOKEN=` ваш токен, сохраните, закройте.
3. Снова запустите `zapusk.bat`. Первый раз он минуту ставит библиотеки.
4. Напишите своему боту `/myid`, впишите число в `.env` в строку `ADMIN_IDS=` и перезапустите `zapusk.bat`.

Готово: бот доступен всем, кто его найдёт или перейдёт по ссылке `t.me/адрес_бота`.

## Чтобы бот работал без открытого окна

1. Один раз запустите `zapusk.bat` и проверьте, что бот отвечает. Закройте окно.
2. Дважды щёлкните `avtozapusk-vkl.bat`.

Теперь бот работает в фоне, без терминала, и сам запускается при каждом входе в Windows. Если бот упадёт из-за сбоя сети, он перезапустится через 5 секунд. Что он делал, видно в файле `bot.log`.

- Остановить бота и выключить автозапуск: `avtozapusk-vykl.bat`.
- Изменили `texts.py` или `.env`: запустите `avtozapusk-vykl.bat`, затем `avtozapusk-vkl.bat`.
- Случайно запустили второй раз: второй экземпляр сам закроется, конфликта не будет.

Ограничение: бот работает, пока компьютер включён и не спит. Чтобы не засыпал: «Параметры» → «Система» → «Питание» → «Спящий режим» → «Никогда» (при питании от сети).

### Круглосуточно, даже когда компьютер выключен

Нужен сервер: недорогой VPS на Linux (Timeweb Cloud, Beget, Selectel и др.).

```bash
# на сервере, один раз
sudo apt install -y python3-venv git
git clone https://github.com/Yanchek006/IMER.git /opt/imer
cd /opt/imer/bot && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
nano .env                      # BOT_TOKEN, ADMIN_IDS, SITE_URL, LEADS_URL
sudo useradd -r -s /usr/sbin/nologin imerbot && sudo chown -R imerbot /opt/imer
sudo cp deploy/imer-bot.service /etc/systemd/system/
sudo systemctl enable --now imer-bot
```

Обновить после изменений: `cd /opt/imer && git pull && sudo systemctl restart imer-bot`.
Когда бот работает на сервере, на компьютере его выключите (`avtozapusk-vykl.bat`): Telegram не даёт двум копиям одного бота работать одновременно.

## Как поменять тексты
Все тексты, цены, кейсы и ответы на сомнения — в файле `texts.py`. Меняйте слова между кавычками и перезапускайте бота. Код в `bot.py` трогать не нужно.

## Файлы
- `bot.py` — логика бота
- `texts.py` — все тексты
- `.env` — токен и настройки (никому не показывать, в GitHub не отправляется)
- `zapusk.bat` — запуск в окне; `avtozapusk-vkl.bat` / `avtozapusk-vykl.bat` — фоновый режим
- `bot.log` — журнал работы
- `assets/guide_infographics.pdf` — гайд-подарок за квест
- `data/store.json` — пользователи, счётчик заявок, прогресс квеста (создаётся сам)

Ссылки сайта: картинки кейсов бот берёт из `../site/assets/img`, КП — из `../docs`. Поэтому папка `bot` лежит рядом с `site`.
